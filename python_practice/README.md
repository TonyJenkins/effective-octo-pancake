# Python Practice Programs

This collection contains 20 small, standalone exercises, ordered from basic
input and arithmetic through strings, collections, and simple games. Each
program includes a task prompt, a reference implementation, and a sample run.

Try solving the task yourself before reading the implementation. Run a program
from the repository root with Python 3:

```bash
python3 python_practice/01_greeting.py
```

The programs use only the Python standard library.
